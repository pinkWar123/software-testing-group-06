# Compatibility Screenshots

Store one authentic screenshot for every tested matrix cell.

Suggested filename: `<screen>_<os>_<browser>_<device-class>_<cell-id>.png`

Every image must visibly include:

- EMS URL
- Browser identity
- Operating-system identity
- Device identity/class
- Student-ID email overlay in the form `MSSV@....edu.vn`

Do not use AI-generated or fabricated compatibility evidence.
