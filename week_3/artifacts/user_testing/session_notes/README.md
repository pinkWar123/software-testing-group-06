# Per-Session Observation Notes

Create one file per genuine participant:

- `P01_session_notes.md`
- `P02_session_notes.md`
- `P03_session_notes.md`
- `P04_session_notes.md`
- `P05_session_notes.md`

Each file should record consent, start/end time, success status, errors, hesitations, neutral interventions, friction points, think-aloud observations, probe responses, and recording reference. Do not fabricate raw data.
